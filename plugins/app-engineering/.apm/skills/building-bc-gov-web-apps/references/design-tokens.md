# BC Gov Design Tokens (Delegated)

Design tokens (`@bcgov/design-tokens` v5, `--color-*`, `--text-*`, `--surface-*`, and layout/spacing tokens) are maintained centrally in the [`bc-gov-design-system`](https://github.com/richfrem/bc-gov-design-system) skill (`react` / `core` modes) rather than duplicated here.

Install and invoke `bc-gov-design-system` for the full token reference:

```bash
apm install https://github.com/richfrem/bc-gov-design-system --global --target claude,copilot,codex,agy
```

Official upstream docs: <https://www2.gov.bc.ca/gov/content/digital/design-system/foundations/design-tokens>.
